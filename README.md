# 🌐 LingoBridge AI - Offline Edition

An intelligent, 100% client-side multilingual translation and localization platform that runs completely offline using **Ollama** and local LLMs. Built with HTML, CSS, and JavaScript.

## ✨ Features
* **Zero API Costs & Total Privacy:** Runs locally on your machine without sending data to the cloud.
* **Context-Aware:** Adapts translations based on user-defined tone (Professional, Casual, Formal) and domain context (IT, Medical, Legal).
* **Cross-Language Support:** Translates between English, Hindi, Odia, and more.
* **One-Click Actions:** Copy to clipboard and download translations as `.txt` files.

## 🚀 How to Run Locally

1. **Install Ollama:** Download and install [Ollama](https://ollama.ai/).
2. **Download a Model:** Open your terminal and pull a model (e.g., Qwen2 or Llama3):
   ```bash
   ollama run qwen2
